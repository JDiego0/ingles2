# PROYECTO: ENGLISH JOURNEY — PLATAFORMA PERSONAL DE APRENDIZAJE DE INGLÉS A1 → B2

## 1. TU ROL

Actúa como un equipo multidisciplinario compuesto por:

- Un ingeniero de software senior especializado en React, TypeScript y aplicaciones web.
- Un diseñador UX/UI experto en aplicaciones educativas mobile-first.
- Un especialista en adquisición de segundas lenguas y enseñanza comunicativa del inglés.
- Un diseñador instruccional que utiliza recuperación activa, repetición espaciada, aprendizaje contextual y evaluación por competencias.
- Un experto en accesibilidad, aplicaciones PWA y despliegues en GitHub Pages.

Tu misión es DISEÑAR, IMPLEMENTAR, PROBAR Y DOCUMENTAR una aplicación web educativa real, funcional y atractiva para que yo aprenda inglés desde mi nivel actual, aproximadamente A1/A1+, hasta alcanzar competencias cercanas al nivel B2 del MCER (Marco Común Europeo de Referencia).

No quiero únicamente un plan, una maqueta, un documento de recomendaciones ni un prototipo visual. Quiero una aplicación funcional con contenido educativo real, lecciones guiadas, ejercicios interactivos, seguimiento del progreso y un sistema de aprendizaje coherente.

Debes trabajar directamente sobre los archivos del proyecto cuando tengas acceso al entorno de desarrollo.

No te limites a describir código que debería escribirse: implementa el proyecto, ejecútalo, comprueba su funcionamiento y corrige los errores que encuentres.

## 2. CONTEXTO DEL ESTUDIANTE

Diseña el curso para una persona hispanohablante de Colombia con estas características:

- Nivel actual aproximado: A1/A1+.
- Objetivo: desarrollar un inglés práctico para conversar, comprender a otras personas, trabajar en entornos tecnológicos y prepararse para oportunidades laborales remotas.
- Intereses: programación, desarrollo de software, tecnología, soporte técnico, trabajo remoto y situaciones de la vida cotidiana.
- Tiempo disponible: 30 minutos diarios.
- Preferencia de pronunciación: inglés estadounidense.
- Necesita instrucciones en español al principio, con una transición progresiva hacia el inglés.
- Aprende mejor con ejemplos concretos, ejercicios breves, retroalimentación y práctica guiada.
- Se aburre cuando los ejercicios son repetitivos, excesivamente largos o consisten en seleccionar respuestas obvias.
- Puede completar ejercicios con ayuda, pero tiene dificultades para recordar las palabras y construir frases cuando desaparecen las pistas.
- Necesita desarrollar la capacidad de hablar sin guiones, sin traducciones visibles y sin depender de una aplicación que le sugiera las respuestas.
- Prefiere una experiencia clara, práctica, visual, dinámica y fácil de utilizar desde el celular.

La aplicación debe abordar específicamente el problema de reconocer una respuesta correcta sin poder producirla espontáneamente.

La prioridad no es completar muchas lecciones, sino aprender a utilizar activamente el idioma.

## 3. PRINCIPIO PEDAGÓGICO FUNDAMENTAL

Construye el curso alrededor de esta secuencia:

1. Comprender una expresión en contexto.
2. Escucharla y reconocer su pronunciación.
3. Entender su significado y estructura.
4. Repetirla en voz alta.
5. Recuperarla de la memoria sin verla.
6. Utilizarla para crear frases nuevas.
7. Responder preguntas sin opciones de respuesta.
8. Utilizarla en una conversación o situación simulada.
9. Recuperarla días después mediante repetición espaciada.
10. Demostrar que puede utilizarse con suficiente independencia antes de considerarla dominada.

No permitas que el estudiante avance simplemente pulsando botones de «Siguiente» y «Completar».

Distingue claramente entre:

- Reconocer una respuesta.
- Recordar una respuesta con una pista.
- Producir una respuesta sin ayuda.
- Utilizarla espontáneamente en un contexto diferente.

La última categoría debe tener mayor peso en la evaluación del dominio.

La dificultad debe adaptarse progresivamente: primero se proporcionan modelos y pistas; después se retiran gradualmente.

No confundas dificultad con frustración. Si el estudiante no puede responder, proporciona una pista pequeña, después una ayuda mayor y finalmente un ejemplo. Tras mostrar la solución, exige volver a intentarlo sin verla.

## 4. TECNOLOGÍAS Y RESTRICCIONES

Utiliza una arquitectura sencilla, mantenible y gratuita:

- React.
- TypeScript.
- Vite.
- CSS moderno o Tailwind CSS, si su instalación resulta conveniente.
- React Router únicamente si realmente se necesita.
- Git y GitHub.
- GitHub Pages para el despliegue.
- PWA instalable para utilizar la aplicación desde la pantalla de inicio del celular.
- localStorage o IndexedDB para guardar el progreso.
- Web Speech API para síntesis de voz y, cuando esté disponible, reconocimiento de voz.
- Archivos JSON o módulos TypeScript para almacenar el contenido educativo.

Restricciones importantes:

- No requieras un backend para las funciones esenciales.
- No requieras suscripciones, API keys, servicios de pago ni cuentas externas.
- No expongas secretos en el código.
- No dependas de servicios externos para conservar el progreso.
- El curso debe seguir funcionando sin conexión cuando sus recursos y lecciones ya estén almacenados en el dispositivo.
- La voz y el reconocimiento de voz pueden depender del navegador y del dispositivo. Detecta sus capacidades y proporciona alternativas cuando no estén disponibles.
- No afirmes que la pronunciación del estudiante es correcta únicamente porque el reconocimiento de voz transcribió una frase.
- Utiliza rutas relativas compatibles con GitHub Pages y configura correctamente la base de Vite.
- Implementa el manifiesto PWA, iconos y un service worker funcional. Evita estrategias de caché que mantengan versiones antiguas indefinidamente.
- No incluyas funcionalidades que parezcan operativas pero no funcionen realmente.

Antes de instalar dependencias, inspecciona el proyecto existente. Si está vacío, crea la estructura necesaria. Si ya contiene código útil, conserva lo que corresponda.

## 5. EXPERIENCIA VISUAL Y DISEÑO UX/UI

Diseña una interfaz moderna, atractiva y profesional, comparable en claridad a una buena aplicación educativa comercial, sin copiar marcas ni diseños propietarios.

La interfaz debe ser mobile-first y funcionar especialmente bien en un teléfono Android.

Características:

- Diseño limpio, agradable y poco recargado.
- Tarjetas visuales con jerarquía clara.
- Tipografía legible.
- Botones suficientemente grandes para utilizar con los dedos.
- Indicadores de avance visibles.
- Animaciones discretas y rápidas.
- Estados claros para respuestas correctas, incorrectas y pendientes.
- Modo claro y oscuro.
- Navegación sencilla.
- Accesibilidad mediante teclado y lectores de pantalla.
- No depender exclusivamente de colores para comunicar resultados.
- Evitar pantallas con demasiado texto.
- Evitar interfaces que parezcan formularios interminables.
- No utilizar elementos decorativos que distraigan del aprendizaje.

Toda la aplicación debe estar en español al principio, pero el contenido que se aprende debe estar en inglés estadounidense.

A medida que el estudiante avance, aumenta progresivamente el uso del inglés en las instrucciones.

## 7. DIAGNÓSTICO INICIAL

Antes de comenzar, ofrece una prueba diagnóstica breve de entre 5 y 10 minutos.

Evalúa de forma preliminar:

- Vocabulario frecuente.
- Comprensión de frases sencillas.
- Construcción de oraciones.
- Comprensión auditiva cuando sea posible.
- Capacidad para producir frases sin opciones.
- Conocimientos gramaticales esenciales.
- Respuesta a preguntas personales básicas.

La prueba debe incluir preguntas abiertas, no solo selección múltiple.

Al finalizar:

- Presenta un perfil de fortalezas y dificultades.
- Establece un punto de partida provisional.
- Recomienda la primera lección.
- Guarda el resultado.
- Permite repetir el diagnóstico posteriormente para comparar resultados.

No declares que una prueba breve certifica un nivel MCER. Preséntalo como una estimación orientativa.

## 8. ESTRUCTURA DEL CURSO

Construye una ruta progresiva desde A1 hasta B2, dividida en módulos, unidades y lecciones.

Organiza los contenidos por funciones comunicativas, situaciones reales y competencias lingüísticas. No organices el curso exclusivamente por reglas gramaticales.

Incluye como mínimo las siguientes áreas:

### Etapa A: Fundamentos A1

- Presentarse y dar información personal.
- Países, nacionalidades, ocupaciones y estudios.
- Verbo to be.
- Pronombres y posesivos.
- Presente simple.
- Rutinas y horarios.
- Preguntas con what, where, when, who, why y how.
- Do y does.
- There is y there are.
- Artículos, plurales y cuantificadores básicos.
- Gustos, preferencias y habilidades.
- Familia, hogar y ciudad.
- Comida, compras, precios y direcciones.
- Can, can't y solicitudes sencillas.
- Pronunciación de sonidos frecuentes.
- Comprensión de conversaciones cortas.

### Etapa B: Desarrollo A2

- Pasado simple y pasado de to be.
- Verbos regulares e irregulares frecuentes.
- Futuro con going to y will en contextos habituales.
- Present continuous.
- Comparativos y superlativos.
- Present perfect introductorio y su contraste con el pasado simple.
- Planes, experiencias y acontecimientos.
- Expresar opiniones, preferencias y razones.
- Invitaciones, peticiones, disculpas y agradecimientos.
- Conversaciones telefónicas y mensajes.
- Viajes, salud cotidiana y resolución de problemas.
- Conectores básicos.
- Comprensión de relatos y diálogos más largos.

### Etapa C: Consolidación B1

- Explicar experiencias, objetivos y decisiones.
- Narrar acontecimientos con claridad.
- Present perfect y pasado simple.
- Present perfect continuous cuando corresponda.
- Condicionales cero, primero y segundo.
- Modales de obligación, posibilidad, consejo y deducción básica.
- Voz pasiva frecuente.
- Reported speech introductorio.
- Oraciones relativas.
- Conectores para argumentar.
- Expresar acuerdo, desacuerdo y matices.
- Resolver malentendidos.
- Conversaciones más largas sin preparación.
- Comprender audio natural de dificultad intermedia.
- Redactar correos y textos coherentes.
- Entrevistas laborales y presentación profesional.

### Etapa D: Consolidación B2

- Defender y matizar opiniones.
- Argumentar a favor y en contra.
- Comparar alternativas y justificar decisiones.
- Expresar hipótesis, probabilidad, certeza y duda.
- Condicionales mixtos cuando sean pertinentes.
- Modales en pasado.
- Estructuras pasivas y causativas frecuentes.
- Reported speech avanzado.
- Inversión y estructuras enfáticas de uso relevante.
- Collocations y expresiones naturales.
- Phrasal verbs frecuentes en contextos reales.
- Registro formal e informal.
- Comprensión de diferentes acentos estadounidenses.
- Comprensión de conversaciones extensas.
- Presentaciones y explicaciones estructuradas.
- Debates y conversaciones espontáneas.
- Correos profesionales y textos argumentativos.
- Entrevistas laborales en inglés.
- Explicar problemas técnicos y soluciones.
- Participar en reuniones de trabajo.
- Pedir aclaraciones y reformular ideas.
- Comprender y resumir contenidos de dificultad B2.

No enseñes todos estos contenidos de golpe. Introduce cada concepto cuando el estudiante disponga de los conocimientos necesarios para comprenderlo.

Define los prerrequisitos y comprueba que las lecciones se desbloqueen en el orden adecuado.

## 9. CHUNKS: EL NÚCLEO DEL APRENDIZAJE

Construye una biblioteca estructurada de expresiones frecuentes y reutilizables.

Un chunk es una expresión que se aprende como una unidad, por ejemplo:

- I want to...
- I'm trying to...
- I'm looking for...
- I need to...
- I have to...
- I'm going to...
- I used to...
- I've been...
- It depends on...
- The reason is that...
- As far as I know...
- What I mean is...
- Could you explain that again?
- I'm not sure how to...
- Let me think for a second.
- From my point of view...
- I see what you mean, but...
- One of the main reasons is...
- If I had to choose, I would...
- What I would suggest is...

Crea una biblioteca inicial amplia, organizada por nivel, función comunicativa y situación.

Incluye como objetivo de diseño una biblioteca de al menos 600 chunks y collocations útiles, pero prioriza la calidad y la reutilización sobre alcanzar una cifra artificial.

No generes frases aleatorias para rellenar la biblioteca. Cada expresión debe tener una función clara, una traducción natural, ejemplos apropiados para el nivel y ejercicios relacionados.

Cada chunk debe contener:

- Identificador único.
- Expresión en inglés.
- Significado natural en español.
- Nivel MCER estimado.
- Categoría comunicativa.
- Ejemplo contextualizado.
- Audio o síntesis de voz cuando esté disponible.
- Variante con palabras intercambiables.
- Errores frecuentes de hispanohablantes.
- Una pregunta para recuperar la expresión.
- Un ejercicio de producción libre.
- Fecha del último repaso.
- Próxima fecha de repaso.
- Nivel de dominio.
- Historial de errores relevantes.

Enséñame a sustituir componentes de una estructura.

Ejemplo:

I want to learn English.
I want to improve my pronunciation.
I want to find a job.
I want to become a better developer.

Después, pide al estudiante que construya una frase propia.

Evita traducir literalmente expresiones idiomáticas. Explica cuándo se utilizan y cuándo no.

## 10. FORMATO OBLIGATORIO DE CADA LECCIÓN

Diseña cada lección para una duración aproximada de 30 minutos.

La duración debe poder ajustarse si el estudiante necesita más tiempo, sin penalizarlo.

### Fase 1. Calentamiento y recuperación — 4 minutos

Presenta entre tres y cinco elementos previamente estudiados.

Intenta que el estudiante los recuerde sin ver las respuestas.

Incluye elementos vencidos de la repetición espaciada.

### Fase 2. Comprensión contextual — 5 minutos

Presenta una conversación breve o situación real.

Incluye audio cuando sea posible, transcripción y traducción bajo demanda.

Primero, intenta que el estudiante comprenda el significado general.

Después, permite revisar expresiones importantes.

### Fase 3. Chunks nuevos — 5 minutos

Introduce entre tres y cinco chunks nuevos.

Para cada uno:

1. Explica su significado.
2. Muestra su pronunciación mediante audio o síntesis de voz.
3. Proporciona un ejemplo.
4. Explica cómo reutilizarlo.
5. Señala un error frecuente.
6. Comprueba que el estudiante lo comprende.

No introduzcas demasiadas expresiones nuevas en una sola sesión.

### Fase 4. Recuperación activa — 5 minutos

Oculta progresivamente las respuestas.

Ejercicios posibles:

- Mostrar el significado y pedir la frase en inglés.
- Mostrar el inicio de una frase y pedir que se complete.
- Formular una pregunta que requiera el chunk.
- Pedir que se reconstruya una oración después de escucharla.
- Recordar una expresión de una lección anterior.

No permitas que las opciones múltiples sean la actividad predominante.

### Fase 5. Producción libre — 6 minutos

El estudiante debe hablar o escribir en inglés sin disponer de una respuesta modelo visible.

Propón preguntas personales, cambios de contexto y situaciones comunicativas.

Ejemplos:

- Tell me about your daily routine.
- What are you learning these days?
- Why do you want to improve your English?
- Describe a problem you solved recently.

Ajusta las preguntas al nivel.

Permite responder mediante texto o voz. Si el reconocimiento de voz no funciona, utiliza grabación de audio cuando sea compatible o respuestas escritas como alternativa.

### Fase 6. Evaluación y cierre — 5 minutos

Evalúa lo aprendido mediante preguntas nuevas, no mediante la repetición exacta de los ejercicios anteriores.

Muestra:

- Qué expresiones se recuperaron correctamente.
- Cuáles necesitaron pistas.
- Cuáles todavía no se recuerdan.
- Qué errores conviene corregir.
- Qué se repasará mañana.
- Una frase o idea que el estudiante pueda expresar por sí mismo.

La sesión debe terminar con una pequeña victoria comunicativa: expresar algo útil en inglés sin leer un guion.

El tiempo asignado a cada fase es orientativo. Si una actividad requiere una respuesta extensa, no sacrifiques la calidad pedagógica para cumplir un cronómetro rígido.

## 11. REPETICIÓN ESPACIADA Y MEMORIA

Implementa un sistema de revisión local.

Como calendario inicial, utiliza intervalos aproximados de:

- Primera revisión: el mismo día.
- Segunda revisión: un día después.
- Tercera revisión: tres días después.
- Cuarta revisión: siete días después.
- Quinta revisión: catorce días después.
- Sexta revisión: treinta días después.

Ajusta los intervalos según el rendimiento.

Si el estudiante recuerda una expresión espontáneamente, aumenta gradualmente el intervalo.

Si falla, ofrece una pista, muestra el ejemplo y programa un nuevo intento más cercano.

No marques como dominada una expresión simplemente porque se seleccionó correctamente una opción múltiple.

Considera el grado de ayuda requerido, la capacidad de producir una frase y el uso en contextos diferentes.

Incluye una pantalla de repasos pendientes con sesiones breves que puedan completarse incluso cuando el estudiante tenga poco tiempo.

El sistema debe distinguir entre elementos nuevos, en aprendizaje, en repaso y dominados provisionalmente.

Incluye:

- Evaluaciones iniciales.

- Pruebas de comprensión auditiva.

- Comparación del desempeño a lo largo del tiempo.

El progreso debe mostrar gráficos sencillos por semana y por competencia.

Incluye una sección «Antes podía / Ahora puedo» con evidencias concretas, como producir una presentación personal, narrar una experiencia o explicar un problema técnico.

Cuando corresponda, identifica los descriptores del MCER que se están trabajando.

La aplicación puede estimar el progreso, pero debe aclarar que no certifica oficialmente el nivel.

## 13. CONVERSACIÓN INTERACTIVA

Implementa un modo de conversación que permita practicar sin guiones.

Debe incluir situaciones como:

- Conocer a una persona.
- Hablar de intereses y rutinas.
- Pedir información.
- Explicar un problema.
- Hacer una llamada.
- Participar en una entrevista.
- Hablar sobre programación.
- Resolver una incidencia de soporte técnico.
- Explicar una decisión.
- Defender una opinión.

La aplicación debe presentar una pregunta en inglés, permitir una respuesta y después proporcionar retroalimentación.

Si el estudiante se bloquea:

1. Espera a que intente responder.
2. Ofrece una pista contextual.
3. Si sigue bloqueado, ofrece una estructura incompleta.
4. Si es necesario, muestra una respuesta modelo.
5. Pide una nueva respuesta con palabras propias.
6. Repite el patrón en una situación diferente más adelante.

No interrumpas continuamente cada error. Durante la conversación, prioriza la comunicación. Al terminar, selecciona los dos o tres errores más importantes.

Incluye un modo de simulación en el que las preguntas cambien según la respuesta del estudiante. Cuando no exista una API de inteligencia artificial, utiliza diálogos ramificados y escenarios predefinidos de calidad.

No presentes una conversación basada en respuestas predefinidas como si fuera una inteligencia artificial generativa.

- Escucha con transcripción.
- Dictados breves.
- Ejercicios de identificación de palabras.
- Práctica de ritmo, acentuación y contracciones.
- Diferenciación de sonidos problemáticos para hispanohablantes.

Prioriza expresiones estadounidenses naturales.

Incluye frases con contracciones como I'm, don't, didn't, I've, we're y would've cuando el nivel lo permita.

No exijas una pronunciación idéntica a la de un hablante nativo. Prioriza inteligibilidad, comprensión y capacidad de comunicarse.

Si la síntesis de voz o el reconocimiento de voz no están disponibles, explica la limitación y ofrece un ejercicio alternativo.

## 17. CONTENIDO EDUCATIVO REAL

No entregues una aplicación vacía con módulos cuyos títulos prometan contenido que no existe.

Implementa un conjunto inicial de lecciones completas y funcionales, suficiente para utilizar la aplicación desde el primer día.

Crea una arquitectura de contenido que permita ampliar el curso sin modificar los componentes visuales.

Cada lección debe incluir sus instrucciones, ejemplos, ejercicios, respuestas esperadas, explicaciones y criterios de evaluación.

Todas las respuestas deben validarse de forma razonable: aceptar variantes correctas, contracciones y diferencias de puntuación cuando corresponda.

No uses una comparación de cadenas excesivamente estricta que rechace respuestas válidas.

Incluye pruebas de contenido para detectar identificadores duplicados, referencias inexistentes, preguntas sin respuesta y lecciones sin ejercicios.

Genera contenido auténtico y progresivo. No repitas la misma plantilla cambiando únicamente una palabra.

Para llegar a una biblioteca extensa, organiza el contenido por lotes coherentes y amplíalo gradualmente. No sacrifiques calidad por generar cientos de elementos superficiales.

## 18. FUNCIONAMIENTO Y PERSISTENCIA
